== Synopsis
[verse]
// tag::synopsis[]
aerospace focus-mode [-h|--help]
// end::synopsis[]

== Description

// tag::body[]
{manpurpose}

Focus Mode temporarily centres the focused window using the configured
`single-window-width-rules`. Other windows keep their tiled positions beneath a
dark, click-through backdrop. Press the binding again to restore the normal
view. With three or more displays, the focused window moves to the middle
display; with two, it moves to the macOS main display. With one display, it
stays there. The window returns to its original tiled position when Focus Mode
ends. The window tree and tile sizes are not changed.

Focus Mode follows focus to another window in the same workspace. Switching
workspaces, losing the focused window, or disabling AeroSpace exits the mode.

Add a binding such as `ctrl-alt-cmd-z = 'focus-mode'` to your configuration.

// end::body[]
