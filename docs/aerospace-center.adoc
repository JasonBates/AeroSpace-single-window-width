== Synopsis
[verse]
// tag::synopsis[]
aerospace center [-h|--help] [--window-id <window-id>]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The window keeps its size unless it is larger than the monitor, in which case it is shrunk to fit.
The command fails for tiling windows and for windows on workspaces that are not visible.

Combine it with `layout floating` and `resize` in `on-window-detected` callbacks to open a window
floating, sized and centred:

[source,toml]
----
[[on-window-detected]]
    if.app-id = 'com.apple.QuickTimePlayerX'
    run = ['layout floating', 'resize width 1600', 'resize height 928', 'center']
----
